# PeopleBase 📋

App de gestión de contactos para pequeñas empresas (pymes). Administra tus **clientes**, **empleados** y **proveedores** en una sola interfaz limpia y organizada.

Desarrollado como parte del Bootcamp de 4Geeks Academy.

---

## 🚀 Demo en vivo

> https://peoplebase-a08l3swiv-linar3s-projects.vercel.app/

---

## ✨ Funcionalidades

- 📁 3 listas separadas: Clientes, Empleados, Proveedores
- ➕ Crear, editar y eliminar contactos
- 🔍 Búsqueda en tiempo real por nombre o email
- ⚠️ Modal de confirmación antes de eliminar
- 📱 Interfaz limpia y responsiva

---

## 🛠️ Tecnologías usadas

| Capa | Tecnología |
|------|-----------|
| Frontend | React 18 |
| Estado global | Context API + useReducer |
| Rutas | React Router v6 |
| Bundler | Vite |
| API | 4Geeks Playground Contact API |
| Deploy | Vercel |

## ⚙️ Instalación local

**1. Clona el repositorio**
```bash
git clone https://github.com/LinaR3/contact_List.git
cd contact_List
```

**2. Instala las dependencias**
```bash
npm install
```

**3. Crea tu archivo `.env`**
```bash
cp .env.example .env
```

**4. Inicia el servidor de desarrollo**
```bash
npm run start
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador.

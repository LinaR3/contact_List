# PeopleBase 📋

A lightweight contact management app for small businesses. Manage your **clients**, **employees**, and **providers** in one clean interface.

Built as part with 4Geeks

## ✨ Features

- 📁 3 separate contact lists: Clients, Employees, Providers
- ➕ Create, edit and delete contacts
- 🔍 Live search by name or email
- ⚠️ Confirmation modal before deleting
- 📱 Clean and responsive UI

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|-----------|
| Frontend | React 18 |
| Global State | Context API + useReducer |
| Routing | React Router v6 |
| Bundler | Vite |
| API | 4Geeks Playground Contact API |
| Deploy | Vercel |

## ⚙️ Local Setup

**1. Clone the repo**
```bash
git clone https://github.com/LinaR3/contact_List.git
cd contact_List
```

**2. Install dependencies**
```bash
npm install
```

**3. Create your `.env` file**
```bash
cp .env.example .env
```

**4. Start the dev server**
```bash
npm run start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
